# ร้านไพ่เหมียวจันทร์ · Moonpaw Pet Tarot

เว็บแอปดูดวงไพ่ยิปซีสำหรับสัตว์เลี้ยง ธีม Kawaii Pastel Tarot ผู้ใช้เดินเข้าร้านแบบเกม
คุยกับ "มาดามโมจิ" แล้วเปิดไพ่ดวงรายวัน (1 ใบ) หรือรายเดือน (3 ใบ) พร้อมสะสมไพ่ครบ 78 ใบ

## เริ่มใช้งาน

```bash
npm install
npm run dev            # เปิด http://localhost:5173
npm run build          # เว็บ static ปกติใน dist/ (อัปขึ้น Netlify / Vercel / S3 ได้เลย)
npm run build:single   # ไฟล์เดียว dist/index.html รวมทุกอย่างไว้ในไฟล์เดียว เอาไปส่งต่อหรือฝังได้
```

ไม่มี framework และไม่มี dependency ตอนรัน (มีแค่ Vite ตอน build) ฟอนต์ดึงจาก Google Fonts

## Journey

หน้าร้าน → ทักทาย → แนะนำน้อง (ชื่อ + ประเภท) → **ห้องหลัก** (เลือกจุดในร้าน)
- โต๊ะมาดาม → เลือกแบบดูดวง → สับ & เลือกไพ่ → เปิดไพ่ → คำทำนาย
  - ดวงรายวัน 1 ใบ (วันละครั้ง) · ดวงรายเดือน 3 ใบ ต้น/กลาง/ปลายเดือน (เดือนละครั้ง)
  - **ดวงชะตารวม 10 ใบ** ผัง Celtic Cross ดัดแปลงสำหรับสัตว์เลี้ยง (เปิดได้ทุกเมื่อ) คลี่ไพ่ครบทั้ง 78 ใบให้เลือก 10 ใบ มีปุ่ม "ให้มาดามเลือกให้" และ "เปิดทั้งหมด"
- ชั้นสมุดดวง → ปฏิทินเดือนนี้ + คำทำนายที่บันทึกไว้
- ตู้อัลบั้มไพ่ → แท็บ เมเจอร์/ถ้วย/ไม้เท้า/ดาบ/เหรียญ + หน้ารายละเอียดไพ่

ทั้งแอปเป็นฉากเดียว ใช้การเลื่อนกล้องแทนการเปลี่ยนหน้า

### Responsive

- ภาพฉาก (ร้าน/ถนน) วาดใน design space 390×844 และมีฉากขยายออกด้านข้าง แล้วย่อขยายตามความสูงจอ (`layout()` ใน `main.js`)
- ส่วน UI (แผง เมนู ไพ่) เป็น CSS ปกติ แบ่ง 3 โหมดตามขนาดจอ ด้วย class บน `#stage`
  - มือถือ (ค่าเริ่มต้น): แผงเลื่อนขึ้นจากด้านล่างเต็มความกว้าง
  - `.tablet` (กว้าง ≥ 700px แนวตั้ง): แผงอยู่กลางจอ กว้างไม่เกิน 620px
  - `.wide` (แนวนอน อัตราส่วน ≥ 1.2 เช่น iPad แนวนอน, โน้ตบุ๊ก, มือถือแนวนอน): แผงเป็น side panel ด้านขวา และฉากเลื่อนไปทางซ้าย
  - `.short` (สูง < 560px): ลดระยะและขนาดตัวอักษรสำหรับมือถือแนวนอน
- ขนาดไพ่ในโซนสับ/เปิดไพ่ ปรับตาม `--k` ที่คำนวณจากขนาดจอ

## คำทำนาย

- **เลือกได้เฉพาะน้องแมวและน้องหมา** และคำทำนายแยกตามชนิด มาจากเอกสาร *ไพ่ดวงน้องขนฟู ฉบับแมว* และ *ฉบับสุนัข* (ทั้ง 78 ใบ ตั้งตรง/กลับหัว) อยู่ใน `src/readings.js`: ต่อใบมี น้องเป็นแบบนี้ · หมายความว่า · สิ่งที่เจ้าของควรทำ
- สิ่งที่เจ้าของควรทำของแต่ละใบถูกใช้เป็น “มาดามโมจิฝากบอกเจ้าของ” และในผัง 10 ใบจะห่อด้วยประโยคตามตำแหน่ง (`POS_TIP` ใน `main.js`) แทนข้อความแม่แบบในเอกสาร ให้อ่านง่ายขึ้น
- ฉบับสุนัข 15 ใบในเอกสารให้คำแนะนำกลับหัวซ้ำกับตั้งตรง จึงใช้คำแนะนำกลับหัวจากฉบับแมวแทน (เนื้อหาใช้ได้กับทั้งคู่) และแก้คำว่า “กระบะทราย” ในเพจเหรียญฉบับสุนัข
- ของนำโชคที่เหมาะกับชนิดเดียวถูกสลับให้ (`ITEM_FIX`) เช่น แมวจะไม่ได้ “สายจูง”
- ข้อมูลเก่าที่เป็นกระต่ายหรือแฮมสเตอร์ถูกเปลี่ยนเป็นแมวอัตโนมัติ
- หัวข้อสั้นของไพ่ (`key`) ชื่อไพ่ สี ของนำโชค และค่าพลัง ยังอยู่ใน `src/data.js`

- เนื้อหาไพ่ทั้ง 78 ใบ มาจากเอกสาร *ไพ่ดวงน้องขนฟู — คำทำนายไพ่ยิปซีสำหรับสัตว์เลี้ยง ครบทั้ง 78 ใบ* (ดัดแปลงจาก Seventy-Eight Degrees of Wisdom ของ Rachel Pollack)
- ไพ่มีทั้ง **ตั้งตรง / กลับหัว** (โอกาสออกกลับหัว 30% ปรับได้ที่ `REV_CHANCE` ใน `main.js`)
- คำแนะนำสำหรับเจ้าของแยกตามกลุ่มไพ่ (`GROUP_ADV`: major / wands / cups / swords / pentacles × ตั้งตรง/กลับหัว)
- ผัง 10 ใบอยู่ใน `POSITIONS` (ชื่อตำแหน่ง, ความหมาย, คำนำ, หัวข้อคำแนะนำ) · ตำแหน่งที่ 2 อ่านแบบตั้งตรงเสมอตามตำรา

## กติกาในแอป

- ปุ่ม "ดาวน์โหลดไว้เล่นในเครื่อง" ที่หน้าร้าน (`downloadApp()` ใน `main.js`) บันทึกแอปทั้งตัวเป็นไฟล์ `moonpaw-pet-tarot.html` ไฟล์เดียว เปิดด้วยเบราว์เซอร์ได้แม้ไม่มีเน็ต (ยกเว้นฟอนต์จาก Google Fonts) ปุ่มจะซ่อนเองเมื่อเปิดจากไฟล์ในเครื่อง · บน claude.ai ใช้ความสามารถ `downloads` และต้องมีไฟล์ `moonpaw-pet-tarot.html` วางคู่กับหน้าเว็บ
- ดวงรายวัน/รายเดือนที่เปิดแล้ว มีนับถอยหลังจนถึงเที่ยงคืน / วันที่ 1 ของเดือนถัดไป (เวลาเครื่องผู้ใช้) และปลดล็อกเองเมื่อครบเวลา

- ดวงรายวันเปิดได้ **วันละครั้ง** รายเดือน **เดือนละครั้ง** ถ้าเปิดซ้ำจะเห็นไพ่เดิมของวัน/เดือนนั้น
- ไพ่จากดวงรายวัน/รายเดือนเข้าอัลบั้มทันทีที่พลิกใบสุดท้าย (ออกจากหน้าก่อนอ่านคำทำนายก็ไม่หาย) · ดวงชะตารวม 10 ใบ **ไม่นับเข้าอัลบั้ม** เพื่อไม่ให้สะสมครบเร็วเกินไป
- ทุกการดูดวงบันทึกลงสมุดดวงอัตโนมัติ (`completeReading()` ใน `main.js`) · การลบออกจากสมุดต้องแตะยืนยันสองครั้ง
- ภาพฉากใช้ WebP (`src/assets/*.webp`) ไฟล์ละ ~250–300KB · ไฟล์ PNG เดิมเก็บไว้เป็นต้นฉบับ ไม่ได้ถูก build แล้ว
- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ (key `moonpaw.v1`) ปุ่ม "ล้างข้อมูลทั้งหมด" อยู่ในหน้าแก้ไขข้อมูลน้อง

## ติดตั้งเป็นแอปบนหน้าจอ (PWA) + เก็บข้อมูลถาวร

ใช้ได้เมื่อเปิดเกมจากเว็บ (https หรือ localhost) เช่นอัปโหลดโฟลเดอร์ `dist-site/` ขึ้น Netlify, Vercel หรือ GitHub Pages · เปิดจากไฟล์ในเครื่องจะไม่มีปุ่มติดตั้ง

- `public/manifest.webmanifest` ชื่อแอป สี และไอคอน (`public/icons/` ทำจากภาพมาดามโมจิ)
- `public/sw.js` service worker: หน้าเว็บดึงจากเน็ตก่อน ถ้าไม่มีเน็ตใช้ฉบับที่เก็บไว้ ส่วนรูป ไฟล์ที่ build แล้ว และฟอนต์เก็บไว้ในเครื่อง → เปิดร้านได้แม้ออฟไลน์ · อยากล้างแคชของทุกเครื่อง ให้เปลี่ยน `CACHE` ในไฟล์นี้
- `src/install.js`
  - Chrome / Edge / Android: ปุ่ม “ติดตั้งร้านไว้บนหน้าจอ” เรียกหน้าต่างติดตั้งของเบราว์เซอร์
  - iPhone / iPad: แสดงขั้นตอน แชร์ → เพิ่มไปยังหน้าจอโฮม (เปิดจากไอคอนแล้ว Safari จะไม่ลบข้อมูลเมื่อไม่ได้เข้าหลายวัน)
  - เปิดจากแอป LINE: คนที่มาครั้งแรกจะถูกส่งไปเปิดในเบราว์เซอร์จริงอัตโนมัติ (`?openExternalBrowser=1`) คนที่เล่นอยู่ใน LINE แล้วจะไม่ถูกย้าย แต่มีปุ่มพร้อมคำเตือนว่าข้อมูลไม่ย้ายตาม · IG / Facebook: บอกวิธีเปิดในเบราว์เซอร์
  - เรียก `navigator.storage.persist()` หลังแนะนำน้องและหลังติดตั้ง เพื่อขอให้เบราว์เซอร์ไม่ลบข้อมูลเกม
- จุดชวนติดตั้ง: ปุ่มเล็กใต้ “เข้าร้านดูดวง” และการ์ดใต้คำทำนาย (กด “ไว้ทีหลัง” จะซ่อน 3 วัน)
- ปุ่ม “ดาวน์โหลดไว้เล่นในเครื่อง” แสดงเฉพาะ build แบบไฟล์เดียวแล้ว (build ปกติมีหลายไฟล์ ดาวน์โหลดหน้าเดียวจะเปิดไม่ได้)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `src/main.js` | state, flow, render ทุกหน้าจอ (ตัวจัดการคลิกใช้ `data-act`) |
| `src/data.js` | ชื่อไพ่ หัวข้อสั้น สี ของนำโชค ค่าพลัง บทพูดมาดามโมจิ |
| `src/readings.js` | คำทำนายแยกแมว/หมา ทั้ง 78 ใบ (สร้างจากเอกสาร .docx) |
| `src/art.js` | **ไฟล์ที่ generate มา** ภาพ SVG ไพ่ทั้ง 78 ใบ + หลังไพ่ + ฉากร้าน + หน้าน้อง ๆ |
| `src/card.js` | `cardHTML(key, width)` และ `petHTML(kind, size)` |
| `src/store.js` | อ่าน/เขียนข้อมูล + ย้ายข้อมูลเก่า (เปลี่ยนเป็นเรียก API ได้ที่ไฟล์นี้ไฟล์เดียว) |
| `src/extras.js` | ราศี/สมพงษ์ วันเกิด คำพูดเสียงในใจน้อง รายการรางวัล |
| `src/share.js` | วาดรูปแชร์ 1080×1920 |
| `src/install.js` | ติดตั้งบนหน้าจอ (PWA) และขอเก็บข้อมูลถาวร |
| `public/` | manifest, service worker, ไอคอนแอป (คัดลอกไปกับ build อัตโนมัติ) |
| `src/icons.js` | ไอคอน SVG เล็ก ๆ |
| `src/moonpaw.css` | motion tokens (transition, keyframes) |
| `src/app.css` | layout และสไตล์คอมโพเนนต์ |

## Key ของไพ่

- Major: `fool, magician, priestess, empress, emperor, hierophant, lovers, chariot, strength, hermit, wheel, justice, hanged, rebirth, temperance, devil, tower, star, moon, sun, judgement, world`
- Minor: `<suit><1-14>` เช่น `cups3`, `wands11` (11 = Page, 12 = Knight, 13 = Queen, 14 = King)

## Motion

| ประเภท | ระยะเวลา | easing |
|---|---|---|
| ฉาก / กล้อง | 1.0–1.1s | `cubic-bezier(.6,0,.2,1)` |
| Sheet / UI | 0.45–0.65s | `cubic-bezier(.2,.8,.2,1)` |
| Pop / พลิกไพ่ | 0.55–0.9s | `cubic-bezier(.3,1.4,.5,1)` |
